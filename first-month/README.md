# First-Month Python Practice Projects

Thư mục này chứa chuỗi các bài thực hành Python trong tháng đầu tiên của chương trình thực tập (Intern Backend Developer). Các bài tập được thiết kế tăng dần về độ khó và độ bao phủ kiến thức, từ lập trình cấu trúc CLI cơ bản đến hướng đối tượng (OOP) và làm việc với tệp tin (File I/O, JSON).

## Danh sách các tuần thực hành

### 1. [Tuần 1: Basic Product CLI](file:///home/linh/VDX-intern/first-month/week1_basic_product_cli/README.md)
* **Mục tiêu**: Làm quen với cú pháp cơ bản của Python (biến, kiểu dữ liệu, vòng lặp `while`/`for`, cấu trúc dữ liệu `list`/`dict`).
* **Sản phẩm**: Một ứng dụng CLI đơn giản quản lý sản phẩm (thêm, hiển thị, tính giá trị kho, tìm kiếm) sử dụng RAM.

### 2. [Tuần 2: Function + Validation](file:///home/linh/VDX-intern/first-month/week2_function_validation/README.md)
* **Mục tiêu**: Tổ chức lại code thành các hàm (Functions), viết docstrings và xử lý ngoại lệ đầu vào bằng `try/except ValueError`.
* **Sản phẩm**: Chương trình CLI quản lý sản phẩm hoàn chỉnh về chức năng nhập liệu và kiểm chuẩn đầu vào (Validation).

### 3. [Tuần 3: OOP Product Manager](file:///home/linh/VDX-intern/first-month/week3_oop_product_manager/README.md)
* **Mục tiêu**: Áp dụng Lập trình hướng đối tượng (OOP), định nghĩa class `Product` và class `ProductManager`, sử dụng hàm khởi tạo `__init__`, các phương thức instance và dunder method `__str__`.
* **Sản phẩm**: Tách file chứa logic hướng đối tượng và thêm tính năng cập nhật số lượng sản phẩm.

### 4. [Tuần 4: File + JSON Mini Project](file:///home/linh/VDX-intern/first-month/week4_file_json_project/README.md)
* **Mục tiêu**: Đọc ghi tệp tin JSON với module `json`, xử lý lỗi File, tổ chức mã nguồn phân tầng (Business Logic/Service & Presentation/CLI), đồng thời viết unit tests với thư viện `unittest`.
* **Sản phẩm**: Ứng dụng quản lý sản phẩm có dữ liệu bền vững (Persistent Data) thông qua file `products.json`, hỗ trợ đầy đủ các thao tác CRUD và kiểm thử tự động.
