# Week 1 - Basic Product CLI

## Kiến thức áp dụng
- Biến (Variables)
- Kiểu dữ liệu cơ bản (str, int, float, bool)
- Input / Output (`input()`, `print()`)
- Câu lệnh điều kiện (if/elif/else)
- Cấu trúc dữ liệu (List, Dictionary)
- Vòng lặp (for, while)

## Bài thực hành: Chương trình quản lý sản phẩm cơ bản (CLI)
Xây dựng một ứng dụng dòng lệnh (CLI) cơ bản quản lý danh sách sản phẩm được lưu trữ trực tiếp trong bộ nhớ RAM dưới dạng danh sách chứa các dictionary.

### Các chức năng chính:
1. **Thêm sản phẩm**: Nhập tên sản phẩm, đơn giá (số thực) và số lượng (số nguyên).
2. **Hiển thị danh sách sản phẩm**: In ra màn hình toàn bộ sản phẩm hiện có dưới định dạng dễ đọc.
3. **Tính tổng giá trị kho**: Duyệt qua danh sách, tính tổng giá trị của từng sản phẩm (`đơn giá * số lượng`) và in ra tổng cộng.
4. **Tìm kiếm sản phẩm**: Tìm kiếm sản phẩm theo từ khóa nhập vào (không phân biệt chữ hoa, chữ thường).
5. **Thoát**: Thoát khỏi chương trình.
